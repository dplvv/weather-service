# Weather Service

Программа на Java для получения погоды через API Яндекс Погоды.

## Что делает программа

- Выводит полный ответ сервиса в формате JSON.
- Показывает текущую температуру.
- Вычисляет среднюю дневную температуру за выбранное количество дней.

Используются Java 17, Maven и Gson.

## Как запустить

1. Открыть проект в IntelliJ IDEA и дождаться загрузки зависимостей Maven.
2. Получить API-ключ в [кабинете Яндекс Погоды](https://yandex.ru/pogoda/b2b/console/home).
3. Открыть **Run → Edit Configurations** и создать конфигурацию **Application**.
4. В поле **Main class** указать:

   ```text
   org.example.WeatherApp
   ```

5. В **Environment variables** добавить:

   ```text
   YANDEX_WEATHER_API_KEY=ваш_ключ
   ```

6. Сохранить настройки и нажать **Run**.

Результат появится в консоли IntelliJ IDEA. Ключ не нужно добавлять в исходный код.

## Настройка

В файле `WeatherApp.java` можно изменить координаты и количество дней:

```java
double lat = 55.75;
double lon = 37.62;
int limit = 3;
```

По умолчанию программа получает погоду для Москвы на три дня, включая текущий.

## Как считается среднее

Программа берёт `parts.day.temp_avg` из первых `limit` элементов массива `forecasts`, складывает значения и делит сумму на количество дней.

Например:

```text
(10 + 12 + 14) / 3 = 12 °C
```

Текущая температура берётся из `fact.temp` и выводится отдельно.

Если ключ отсутствует, запрос не выполнен или необходимых данных нет, программа сообщает об ошибке.
